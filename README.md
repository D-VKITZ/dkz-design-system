# DkZ Design System v2

DkZ Design System v2 — CSS Custom Properties, Glassmorphism, Themes.

## Features

- CSS custom properties architecture for theming
- Glassmorphism design language with backdrop-filter
- Dark mode with neon accent palette (#060608, #fa1e4e, #00ff88)
- Responsive typography system (Inter + JetBrains Mono)
- Component tokens for cards, buttons, badges, inputs, modals

## Tech Stack

CSS3 Custom Properties · HTML5 · Vanilla JavaScript

## Quick Start

```bash
git clone https://github.com/D-VKITZ/dkz-design-system.git
cd dkz-design-system
# Include dkz-theme.css in your project
```
